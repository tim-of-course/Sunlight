## OA-06: boundary, secrets, and execution safety

The hostile-input matrix is covered by real filesystem/process integration tests, not only schemas:

- Path traversal, absolute/host paths, `.git`, `.sunlight`, reserved names, ADS names, and protected output paths are rejected by the path-policy, commit-policy, compatibility-import, record-publication, and MCP argument tests.
- Windows junction/reparse escape is rejected by `ingestion_rejects_a_path_traversing_a_windows_junction`, `no_fixture_cache_reparse_point_is_quarantined_before_reuse`, compatibility-root tamper tests, and the fail-closed source/projection reparse tests.
- Secret paths and recognizable tokens are quarantined before normal persistence. False-positive fixtures distinguish identifiers and documentation from secret values. Status, search, checkpoint, policy, and Git-export tests prove quarantined bytes do not leak.
- Windows execution confinement tests attempt root and descendant writes and loopback access; only the private projection is writable, source and host state stay unchanged, and setup failures never launch command code.
- `oversized_patch_is_rejected_before_any_private_staging_write`, MCP contract tests, and bounded-stdio tests cover malformed arguments, oversized patches, and unexpected output volume while keeping the server usable.
- Promotion tests cover allowed source-like output, ignored output, secret/generated policy rejection, and the 2 MiB oversized-output cap. `oversized_execution_output_promotion_fails_closed_without_native_mutation` proves canonical state and source remain unchanged.
- Runtime-policy and Windows Job Object tests persist command result, environment redaction/digest, network requested/effective status, filesystem-write isolation, timeout, process-tree, CPU, memory, active-process, and output-capture enforcement facts. Unsupported dimensions are reported as `not_enforced`, never as enforced.

No critical or high-severity boundary defect is known in this tested Windows scope. macOS and Linux are not inferred to pass from this evidence; OA-08 must define the public support statement.
